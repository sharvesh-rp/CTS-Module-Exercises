ANSI SQL Using MySQL - Exercise Solutions

Overview:

This repository contains solutions for the ANSI SQL Using MySQL exercises provided as part of the Cognizant Digital Nurture (DN) 5.0 Upskilling Program.
The exercises are based on an Event Management System database and cover fundamental as well as intermediate SQL concepts.

Topics Covered:

SELECT Statements
Filtering and Sorting Data
Aggregate Functions
GROUP BY and HAVING
Joins
Subqueries
Date Functions
Data Analysis Queries
Resource Management Queries
User Engagement Reports
Event Management Queries


Database Tables:

The project contains the following tables:

Users
Events
Sessions
Registrations
Feedback
Resources

How to Execute:

Step 1: Create Database
CREATE DATABASE EventManagement;
USE EventManagement;

Step 2: Execute Schema Script

Run:

source schema.sql;
Step 3: Insert Sample Data

Run:

source sample_data.sql;
Step 4: Execute Exercise Solutions

Run:

source exercise_solutions.sql;
